What Are Data Structures

  • Methods to store and organize data
  • Enable efficient access and modification
  • Python provides built-in, optimized data structures
  • Essential for real-world programming

List

  • Ordered and mutable collection
  • Allows duplicate values
  • Stores mixed data types
numbers = [1, 2, 3]
print(numbers) Output:
[1,2,3] numbers.append(4)
print(numbers) Output:
[1,2,3,4]

List

  • Ordered and immutable collection
  • Faster than lists
  • Data cannot be changed
point = (10, 20)
print(point) Output:
(10, 20)

Set

  • UOrdered collection
  • No duplicate values
  • Supports set operations
unique = {1, 2, 3}
print(unique) Output:
{1, 2, 3}

Python Dictionary

  • Stores key-value pairs
  • Keys must be unique
  • Fast lookup
student = {'name': 'Ram', 'age': 20}
print(unique.items()) Output:
{1, 2, 3}
