Python Numbers


  • Numbers are used to store numeric values
  • Python supports multiple numeric types
  • Used in calculations, logic, and data processing

Python Numerical Types

Integers:

Integers are whole numbers, either positive or negative. In Python, integers have no size limit, so you can use them to represent very large or very small numbers.

Examples:

number = -1234454677 type(number)

Floating-point Numbers:

Floating-point numbers are decimal numbers, either positive or negative. In Python, floating-point numbers are represented using the float type.

Examples:

pie = 22/7 print(pie) type(pie)

Complex numbers:

Complex Numbers are numbers with a real part and an imaginary part. In Python, complex numbers are represented using the complex type.

Examples:

vec = 6 - 3j type(vec)

Arthemetic Operators

  • '+' Addition
  • '-' Subtraction
  • '*' Multiplication
  • '/' Division
  • '%' Modulus:

    '%' Returns the remainder of dividing the left operand by the right operand

  • '**' Exponentiation
  • '//' Floor Division

    '//' Divides the left operand by the right operand and returns the largest integer less than or equal to the result

Type Conversion

You can convert numbers from one type to another in Python, using functions like:

int() float() complex()

Comparison Operators

  • '>' Greater Than

Strings

A string is a sequence of characters:

  • Used to store text type data
  • Defined using single or double quotes

Example:

Creating Strings

  • Single quotes: 'Hello'
  • Double quotes: "Python"
  • Triple Quotes(For Multiline): """This is a
    multiline
    string in Python."""
text1 = "It's a sunny day"
text2 = 'He said "Hello"'
print(text1)
print(text2)

String Operations

  • Indexing and slicing
  • Length using len()

Numbers vs Strings

  • Numbers are used for calculations
  • Strings are used for text
