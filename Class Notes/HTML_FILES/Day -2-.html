Git Quick Review

Before diving into SSH, let's recap the essential workflow:

  • git init — Start a new local repo
  • git clone — Copy a remote repo
  • git add . — Stage your changes
  • git commit -m "message" — Save your snapshot
  • git push — Upload to remote
  • git pull — Download from remote
Git Playground

SSH Key Concept

SSH (Secure Shell) allows you to connect to GitHub without entering your username and password every time you push or pull.

🔑 Private Key

Stays local on your computer. Never share this with anyone.

🌐 Public Key

Added to the Git platform (GitHub/GitLab). It acts as the "lock" that your private key opens.

1. User Configuration

Set your identity so your commits are attributed to you.

Check existing config:

git config --global user.name git config --global user.email

Set your identity:

git config --global user.email "your_email@example.com" git config --global user.name "Your GitHub Username"

2. Generating & Starting SSH Key

Generate the Key

Run this command in your terminal (replace with your email):

ssh-keygen -t ed25519 -C "your_email@example.com"

Start the SSH Agent

This manages your keys in the background:

eval $(ssh-agent -s) ssh-add ~/.ssh/id_ed25519

Copy the Public Key

You need to copy the content of the .pub file to paste it into GitHub:

cat ~/.ssh/id_ed25519.pub

3. Adding Key to GitHub

Follow these steps in your browser:

  1. Go to your Repository on GitHub.
  2. Click Settings.
  3. Navigate to Deploy keys (on the left sidebar).
  4. Click Add deploy key.
  5. Paste your public key and save.

4. Using SSH for Remotes

Clone a Repo via SSH

Instead of HTTPS, use the SSH URL:

git clone git@github.com:user/repo.git

Change existing Remote from HTTPS to SSH

If you already cloned via HTTPS, switch to SSH with this command:

git remote set-url origin git@github.com:user/repo.git

Git Master Cheat Sheet

Basic Workflow

  • git status — Check state
  • git add . — Stage all
  • git commit -m "..." — Save
  • git push -u origin <branch> — Upload
  • git pull origin main — Update

Branching & Stashing

  • git branch — List branches
  • git checkout -b <name> — New branch
  • git checkout <name> — Switch branch
  • git branch -D <name> — Delete branch
  • git stash — Temporarily save work
  • git stash pop — Restore work
