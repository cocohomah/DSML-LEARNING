Git/GitHub for Version Control

Git is a distributed version control system that keeps a history of all changes and enables collaboration.

Core Concepts

  • Repository (Repo): Project storage with full history.
  • Commit: A snapshot of changes.
  • Branch: A parallel line of development.
  • Push/Pull: Uploading and downloading changes.

Essential Commands

  • git init — Create a new repository
  • git clone [url] — Copy an existing repository
  • git add . — Stage all changes for commit
  • git commit -m "message" — Save a snapshot
  • git push — Upload local changes to remote
  • git merge — Combining changes from branches
  • git clone — Downloading a copy of a repo
  • git pull — Get latest updates from remote
